1. Open the ESP32 control page

In Serial Monitor at 115200 baud, find:

Local page: http://<board-IP>/

Open that address from a phone or laptop on the same Wi-Fi network. If the startup line has scrolled away, press the board’s EN/Reset button with Serial Monitor open.

Shows live estimated SPL, LED state and MQTT health. Use this page to save thresholds and calibration; MQTT Explorer is for observing the messages.

2. Connect MQTT Explorer

Open your installed MQTT Explorer app. Add a connection named Building noise:

Protocolmqtt://
Hostbroker.emqx.io
Port1883
Usernameemqx
Passwordpublic — lab broker credential
Encryption / TLSOff
Client IDKeep a unique Explorer ID

In Advanced → subscriptions, replace the broad # subscription with:

iot2026/harlen-group01/noise/#

Save and connect. Expand this topic and select telemetry:

iot2026
  harlen-group01
    noise
      noise-mic-F42DC976B9E4
        telemetry
        status
        availability
telemetry: fresh JSON approximately every second. Watch estimated_spl_db, state, sensor_ok and sequence.
status: retained last state for future board 2.
availability: online/offline; an online value alone does not prove fresh data.
Custom subscriptions are supported by MQTT Explorer.

3. Open Grafana

Open the building noise dashboard on this computer.

Usernameadmin
PasswordYour GRAFANA_ADMIN_PASSWORD value in cloud/.env
Groupharlen-group01
Microphonenoise-mic-F42DC976B9E4

Use the last 15 minutes and 5-second refresh. The top panels require a reading from the last 15 seconds; the graph shows historical data.

No data in a current-value panel means no fresh stored reading. Check board MQTT health and Telegraf logs rather than treating retained status as current.

4. Check InfluxDB storage directly

Open your lab InfluxDB Cloud instance and log in with your InfluxDB account.

Data Explorer: bucket environment_lab → measurement noise_monitor → location building_exterior → field estimated_spl_db.

Flux query for the last 15 minutes
from(bucket: "environment_lab")
  |> range(start: -15m)
  |> filter(fn: (r) => r._measurement == "noise_monitor")
  |> filter(fn: (r) => r.location == "building_exterior")
  |> filter(fn: (r) => r._field == "estimated_spl_db")
Filtering by building_exterior excludes the labelled software test points. Query reference: InfluxDB Flux guide.

Start or inspect the computer-side services

docker compose --env-file cloud/.env -f cloud/docker-compose.yml up -d

docker compose --env-file cloud/.env -f cloud/docker-compose.yml logs --tail=30 telegraf
Run from the PlatformIO project directory. Telegraf’s “Connected” line confirms the broker subscription; write errors indicate a database/network problem.
